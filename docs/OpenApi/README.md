# OpenAPI 文档

OpenAPI 面向甲方及合作方的服务端应用，不适合在浏览器、App、小程序等无法安全保管 `Client Secret` 的环境中直接调用。

## 接入步骤（授权书模式）

1. 运营人员在管理后台创建「授权包」，并绑定或自动创建 OpenAPI 凭据。
2. 在「授权包管理」下载 `.license` 授权书，连同 `public.pem` 通过安全渠道交付。
3. 被授权方配置核验地址、授权书路径与公钥；从授权书解析 `Client ID` / `Client Secret` 及有效期等，无需再逐项配置。
4. 调用方按照[认证、加密与验签协议](认证、加密与验签.md)构造请求（凭据来自授权书）。
5. 按具体接口文档处理业务响应。

授权书含调用密钥，泄露后应立即在后台轮换 Secret 并重新下载下发。

## 接口

- [授权校验](授权校验.md)：`POST /openapi/v1/leases/valid`

所有接口必须使用 HTTPS。
