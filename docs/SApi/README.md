# SAPI 接口文档

服务端应用对接中台的入口为 `/sapi`，不使用版本前缀。接口以当前实现为准。

| 文档 | 内容 |
| --- | --- |
| [接入、鉴权及公共约定](authentication.md) | APP_KEY / APP_SECRET、签名、响应结构、错误、分页、可执行 PHP 示例 |
| [Ping](ping.md) | 连通性及凭证检测 |
| [用户](users.md) | 用户新增、分页、详情、更新、软删除 |
| [企业](enterprises.md) | 企业资料 CRUD |
| [组织](organizations.md) | 组织资料 CRUD 与上下级关系 |
| [企业职工](employees.md) | 企业关联已有用户、职工资料 CRUD |
| [企业应用套餐](subscriptions.md) | 企业与应用绑定、独立套餐 CRUD |

建议接入顺序：后台注册并启用应用 → 保存凭证 → 调用 ping → 创建用户 → 创建企业 → 关联职工与组织 → 为企业绑定应用套餐。

所有接口均需要签名。示例中的 ID、手机号、企业名称和时间仅用于说明；签名、时间戳、nonce 必须在调用时生成。
当前有效应用凭证可管理全量中台目录，没有按调用应用隔离企业数据；嵌套路由会校验关联记录属于路径中的企业。

接口成功响应示例基于 SQLite 测试环境实际返回，meta 数值已统一为示意值。数据库驱动可能影响未显式转换字段的标量类型，详见各文档。

## 后台维护

Admin → 中台管理 → 企业管理 → 编辑企业，下方提供“职工”“应用套餐”页签，可新增、编辑、移除当前企业的关联。仅超级管理员可访问该企业管理入口。
